# B8A1 – Assignment: Problem Solving with TypeScript & OOP

## 📌 Assignment Overview

This assignment focuses on developing practical skills in TypeScript fundamentals, advanced type systems, generics, asynchronous programming, and Object-Oriented Programming (OOP).

The main objective is to strengthen problem-solving abilities and understand how TypeScript helps developers write clean, reusable, maintainable, and type-safe code.

## 💻 Problem Solving (50 Marks)

All coding solutions are implemented in a single TypeScript file named `solutions.ts`.

The assignment covers the following concepts:

- Optional and default parameters
- Union types and type narrowing
- Readonly tuples
- Rest parameters and generics
- Interfaces and array filtering
- Generic constraints using `keyof`
- Classes, inheritance, and access modifiers
- Asynchronous programming with Promise, resolve, and reject
